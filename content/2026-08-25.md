# Topic 70：🛠️ 你的第一个组合——用 1–2 只宽基 ETF 或一个 robo 组合起步，金额一定要小

> 从 Topic 66 到 Topic 69，我们把「进场」这件事从头到尾拆了个遍：**选平台**（Topic 66）、**选 robo**（Topic 67）、**开户入金**（Topic 68）、**定投纪律**（Topic 69）。工具备齐了，规则也懂了。现在到了最激动人心、也最容易搞砸的一步——**真刀真枪地搭起你人生的第一个投资组合。**
>
> 但在你下单之前，我要先泼一盆冷水，也是这一课唯一需要你刻进骨子里的一句话：
>
> **你的第一个组合，目标不是「赚钱」，而是「用最小的代价，把整套流程和你自己的情绪，完整地跑通一遍」。**
>
> 新手最大的误区，是把「第一个组合」当成一场必须赢的豪赌，于是把攒了很久的一大笔钱，一次性重仓压上去。这几乎是所有新手血亏离场的起点。这一课要带你走另一条路：**先搭一个极简、分散、金额小到「就算明天腰斩你也睡得着」的组合**，把它当成一台**训练模拟器**——真金白银带来的情绪波动是真实的，但亏损的绝对金额小到伤不了你。等你亲身跑过一轮涨跌、确认自己扛得住、流程也顺了，**再谈放大**。

---

## 一、第一个组合的真正使命：不是收益，是「跑通流程 + 认识自己」

先想清楚一件事：**你现在最缺的，不是钱，是「经验」和「对自己的了解」。** 而这两样东西，只能用真金白银、在真实的涨跌里买到——但你可以选择**用很小的学费去买**。

第一个组合要帮你验证四件、书本永远教不会你的事：

1. **流程能不能顺畅跑通**——从下单、成交、看到持仓，到分红到账、定投自动扣款，中间任何一个环节卡住（换汇没到位、佣金比想象高、账户被风控），你都要在**金额小、损失小**的时候发现它，而不是重仓之后。
2. **你到底扛不扛得住波动**——Topic 29–30 讲过，「风险承受能力」有一半是**心理意愿**，而这个意愿**只有在你账户真的飘红/飘绿时才测得准**。问卷上你可以勇敢地填「能承受 -30%」，但当账面数字真的少了一截，你半夜会不会睡不着、会不会手贱割肉？**只有小仓位的真实体验能告诉你答案。**
3. **你会不会犯那些「明明学过却还是犯」的错**——追涨杀跌、频繁查看、看到别人的币涨了就 FOMO 换仓……这些行为偏误（Topic 72 之后会系统讲）在纸面上你都懂，但**只有真实持仓能照出你的原形**。
4. **这套策略适不适合你的生活节奏**——你是想彻底托管、连 App 都懒得开（→ robo），还是愿意每月花十分钟自己下单、图个更低费率（→ DIY ETF）？

> **核心心态**：把第一个组合当**驾校练车**，不是**上高速飙车**。练车时剐蹭一下，是学费；高速上出事，是灾难。**金额小，就是给自己配的那套安全气囊。**

## 二、两条起步路线：自己搭（DIY ETF） vs 托管（Robo）

搭第一个组合，主流有两条路，没有绝对优劣，取决于你愿意付出多少「参与度」来换多少「省心」。这其实是 Topic 54（主动 vs 被动）、Topic 67（robo 怎么选）在你身上的**第一次真实落地**。

| | **路线 A：DIY——自己买 1–2 只宽基 ETF** | **路线 B：Robo——买一个托管组合** |
|---|---|---|
| **你要做的** | 自己选 ETF、自己下单、自己定投、自己再平衡 | 回答风险问卷 → 选一个风险等级 → 自动扣款，剩下全托管 |
| **成本** | **最低**：只付 ETF 的费率（Topic 56，约 0.07%–0.22%）+ 券商佣金 | 费率 + **额外的 robo 管理费**（约 0.3%–1%/年，Topic 67） |
| **省心度** | 中——需要你亲手操作、定期再平衡 | **最高**——再平衡、分红再投资全自动 |
| **透明度/掌控** | **完全掌控**，你清楚每一分钱买了什么 | 组合是黑箱化的一篮子，掌控力弱一些 |
| **适合谁** | 想学、想省费、愿意每月花几分钟的人 | 想彻底「设置后遗忘」、把省心费当值得的人 |
| **新加坡例子** | IBKR 上买 **VWRA / IWDA**（UCITS 全球股票，Topic 57）；或经 CDP 持 SGX 上市的本地 ETF | **Endowus**（唯一支持 CPF/SRS 投资）、**Syfe**、**StashAway** 的一个入门风险组合 |

**给新手的建议**：两条路都对。如果你**想真正学会投资的骨架**，DIY 一只全球股票 ETF 是最好的教材，因为它逼你理解每一步；如果你**自认没时间、也不想操心，只求长期稳稳在场**，一个低风险的 robo 组合能帮你把「坚持」这件最难的事自动化。**很多人的最优解是：先用 robo 养成定投习惯，同时用一小笔钱 DIY 一只 ETF 练手，慢慢过渡。**

## 三、把组合做「极简」：为什么一两只宽基 ETF 就够了

新手总以为「组合」意味着要买很多东西——十几只股票、几只基金、再撒点币，弄得越复杂越像「专业」。**恰恰相反。对新手，最好的第一个组合是极简到近乎「简陋」的。** 原因有三：

- **一只宽基 ETF，内部已经帮你分散好了。** 一只 VWRA（追踪 FTSE All-World）里面就装着**全球约 3,700 家公司**（呼应 Topic 55 ETF 运作、Topic 59 分散的数学）。你买一只，就等于同时持有了美股、欧股、日股、新兴市场……**分散早已在 ETF 内部完成，你不需要再自己拼几十只股票去「手动分散」。**
- **越简单，越不容易犯错、越好坚持。** 组合里的东西越多，你要盯的、要纠结的、要再平衡的就越多，**手贱操作和情绪波动的机会也越多**。极简组合让你几乎「无事可做」——而对新手，「无事可做」恰恰是最好的状态。
- **先跑通再复杂化。** 你完全可以从**一只全球股票 ETF** 起步（100% 股票），跑顺了、也确认自己扛得住波动后，再考虑加**一只债券 ETF** 来降波动（这就是 Topic 63 讲的股债配置的雏形）。**复杂度应该随你的经验增长，而不是一上来就拉满。**

**三档极简模板**（按你的风险意愿从进取到保守）：

| 组合 | 构成 | 特点 | 适合 |
|---|---|---|---|
| **① 单基金 · 全股** | 100% 一只全球股票 ETF（如 VWRA） | 最简单，波动最大，长期预期回报最高 | 年轻、离用钱远、扛得住大波动的人 |
| **② 经典股债** | ~60% 全球股票 ETF + ~40% 全球债券 ETF | 波动被债券显著压低（Topic 62 相关性），是 60/40 的雏形 | 想要平衡、见过股市大跌会紧张的人 |
| **③ 稳健打底** | ~40% 股票 + ~60% 债券/现金 | 波动小，回报也低，重在「先不吓跑自己」 | 极度厌恶波动、或用钱期限较近的人 |

> ⚠️ **一个反面典型**：把「第一个组合」搭成 8 只主题 ETF + 3 只个股 + 2 种加密币的「大杂烩」。这不叫分散，叫**混乱**——你既说不清自己到底押注了什么，费用和摩擦还翻倍，更没法坚持。**分散的目标是「一篮子囊括市场」，不是「买得越多越安心」。**

(function(){
  var eqR = document.getElementById('eqR');
  if(!eqR) return;
  var capR = document.getElementById('capR');

  // 教学级长期近似（年化）：全球股票 vs 全球债券
  var EQ = { ret: 0.075, vol: 0.16 };   // 股票：预期 ~7.5%，波动 ~16%
  var BD = { ret: 0.030, vol: 0.05 };   // 债券：预期 ~3%，波动 ~5%
  var CORR = 0.10;                       // 股债相关性（低，Topic 62）

  function money(n){ return 'S$' + Math.round(n).toLocaleString('en-US'); }

  function update(){
    var we = +eqR.value/100, wb = 1-we;
    var cap = +capR.value;
    document.getElementById('eqPct').textContent = (we*100).toFixed(0);
    document.getElementById('bdPct').textContent = (wb*100).toFixed(0);
    document.getElementById('capLbl').textContent = cap.toLocaleString('en-US');

    // 组合预期回报：加权平均
    var ret = we*EQ.ret + wb*BD.ret;
    // 组合波动：含相关性的两资产标准差公式（Topic 59 分散的数学）
    var varp = we*we*EQ.vol*EQ.vol + wb*wb*BD.vol*BD.vol
             + 2*we*wb*CORR*EQ.vol*BD.vol;
    var vol = Math.sqrt(varp);
    // 「坏年份」近似：均值 - 2 个标准差（约百年一遇偏差量级的坏年）
    var badRet = ret - 2*vol;
    var badLoss = cap * badRet;

    document.getElementById('retOut').textContent = (ret*100).toFixed(1) + '%';
    document.getElementById('volOut').textContent = '±' + (vol*100).toFixed(1) + '%';
    document.getElementById('ddOut').innerHTML = badRet < 0
      ? '<span style="color:#d9534f">' + money(badLoss) + '（' + (badRet*100).toFixed(0) + '%）</span>'
      : '<span style="color:#2e9e5b">几乎不亏</span>';

    var oneYearGain = cap*ret;
    document.getElementById('portMeta').innerHTML =
      '正常年份，这 <b>' + money(cap) + '</b> 平均约赚 <b style="color:#2e9e5b">' + money(oneYearGain) +
      '</b>；但波动意味着单年结果会在很大范围内摆动——<b>回报越高的组合，坏年份的亏损也越深</b>，这就是 Topic 25 的风险回报铁律。';

    var feel = document.getElementById('portFeel');
    if (we >= 0.9)
      feel.innerHTML = '🎢 <b>近乎全股</b>：长期回报最高，但坏年份可能亏掉近三分之一本金。<b>只有你真的扛得住账面腰斩、且这笔钱很多年不用，才适合。</b>';
    else if (we >= 0.6)
      feel.innerHTML = '⚖️ <b>股债平衡（偏股）</b>：债券把波动明显压了下来，是很多人第一个组合的甜点区——有成长、也不至于跌到让你失眠。';
    else if (we >= 0.3)
      feel.innerHTML = '🛟 <b>稳健偏债</b>：波动小很多，代价是长期回报也低。适合极度怕波动、或用钱期限较近的人。';
    else
      feel.innerHTML = '🧊 <b>几乎全债/现金</b>：非常稳，但长期可能跑不太赢通胀（回到 Topic 2）。当「练手 + 情绪测试」可以，长期全押债券要想清楚。';
  }
  eqR.addEventListener('input', update);
  capR.addEventListener('input', update);
  update();
})();
</script>

**拖两下你就会发现几条贯穿全课程的规律：**

- **股票比例越高 → 预期回报越高，但波动和「坏年份亏损」也越大**（Topic 25 铁律的直观版）。
- **加入债券 → 组合波动被明显压低**，且因为股债**相关性低**（Topic 62），降波动的效果比单纯「稀释」更好——这就是 Topic 59「分散的数学」在起作用。
- **同样的比例，本金越大，坏年份亏掉的绝对金额越吓人。** 把本金从 S$3,000 拖到 S$50,000，看看那个红色亏损数字——这正是下一节要讲的「**金额小才是你的护身符**」。

## 五、这一课的灵魂：金额，一定要小

前面所有铺垫，都是为了这一句新手铁律：

> **你的第一个组合，投入的金额要小到——就算它明天直接腰斩，你既不影响生活，也不会失眠，更不会被逼着在低点割肉离场。**

为什么「小」这么重要？因为第一个组合真正在测试的，从来不是市场，**是你自己**。而这个测试的「学费」，完全由你投入的金额大小决定。

- **金额小，犯错的代价就小。** 新手一定会犯错——买错标的、手贱乱动、被一次大跌吓到割肉。这些错**必然会发生**，问题只在于**你是用 S$500 学到，还是用 S$50,000 学到**。同样一个「-30% 后恐慌卖出」的错误动作，前者赔掉 S$150 当学费，后者赔掉 S$15,000 伤筋动骨。
- **金额小，情绪才压得住。** Topic 73（损失厌恶）会讲：亏钱的痛，约是赚钱快乐的 2.5 倍。**亏损的绝对金额越大，这种痛越可能压垮你的理智，让你在最不该卖的时候卖出。** 小仓位让你能**冷静地旁观**自己账户的涨跌，把它当数据看，而不是当灾难。
- **金额小，你才敢真的「跑一轮」。** 只有当损失小到无所谓，你才愿意让组合**完整经历一次涨跌周期**，而不是一跌就慌忙清仓。**这一轮完整体验，才是第一个组合最宝贵的产出。**

**那到底多小算小？** 没有唯一答案，但给你几个可操作的锚：

1. **先确保地基**：应急金（Topic 11）备齐、高息债（Topic 12）还清之后，才谈投资——这是 Topic 9「先理财，再投资」的铁律。
2. **一个心理测试**：想象你投入的这笔钱**明天直接归零**。如果你的反应是「有点肉痛但生活照旧」，金额合适；如果是「那我完了/我要睡不着了」，**太大了，砍掉。**
3. **宁小勿大**：第一个组合投**几百到几千新元**级别，通常足够让你把流程和情绪都跑通了。**它的使命是学习，不是致富——致富是「跑通之后、持续几十年」的事，不是「第一笔」的事。**

## 六、🎢 互动二：情绪压力测试——同样是 -30%，小仓位 vs 大仓位对心理的冲击

  shareR.addEventListener('input', update);
  update();

</script>

**把本金从 S$2,000 拖到 S$80,000，盯着那个红色的「蒸发」数字变化。** 市场跌 30% 的比例是一样的，但**你心里的感受完全不同**——因为真正压垮新手的从来不是「跌幅百分比」，而是「**亏掉的绝对金额**」和「**它占你身家的比重**」。第一个组合的全部智慧，就是把这两个数字**主动压到你能冷静旁观的水平**。这样，当大跌真的来临（它一定会来），你才有机会做出正确动作——按纪律继续定投，而不是恐慌清仓。

## 七、新手第一个组合的常见错误清单（照着避坑）

- **❌ 一次性重仓押上全部积蓄** → ✅ 先小额起步，用 DCA（Topic 69）分批投入，把情绪和流程都跑通。
- **❌ 组合搞得极其复杂**（十几只 ETF + 一堆个股 + 币） → ✅ 一到两只宽基 ETF，或一个 robo 组合，**极简优先**。
- **❌ 投的是自己完全不懂的东西**（跟风买热门个股/币） → ✅ 只投你能一句话说清「它是什么、为什么长期向上、会不会归零」的宽基资产（Topic 38–45 的大类资产逻辑）。
- **❌ 每天甚至每小时刷账户，跟着涨跌操作** → ✅ 设成自动定投后**尽量少看盘**（正是下一课 Topic 71 的主题）。
- **❌ 忽视成本，用高佣金平台做小额频繁交易** → ✅ 优先低费率 ETF + 低佣金/低换汇平台（Topic 56、66），别让费用侵蚀小本金。
- **❌ 一跌就停止定投、甚至清仓** → ✅ 下跌恰是 DCA 捡便宜的时候（Topic 69），约法三章不手动干预。
- **❌ 跳过地基直接投**（没应急金、还背着信用卡债） → ✅ 回到 Topic 9–12，先把地基打好，再谈第一个组合。

## 八、一个具体的落地范例（新加坡语境）

把上面所有原则串成一个可以照抄的例子（**仅作教学示范，不是推荐**）：

> 小 A，28 岁，已备好 6 个月应急金、无高息债。她决定这样搭第一个组合：
>
> 1. **路线**：想学、也想省费 → 选 **DIY**，在一个低佣金券商（Topic 66）开户。
> 2. **标的**：极简到只买**一只全球股票 ETF**——UCITS 结构的 **VWRA**（Topic 57 讲过为什么爱尔兰注册 ETF 对新加坡人友好），内部已分散到全球数千家公司，一只搞定。
> 3. **金额**：每月定投 **S$500**（Topic 69 的 DCA），这笔钱就算腰斩她也睡得着——**先跑一年，验证流程和自己的情绪。**
> 4. **自动化**：设成发薪次日自动扣款、自动买入，然后**关掉 App**（Topic 71）。
> 5. **进化**：跑顺一年、确认自己扛得住波动后，再考虑**加一只债券 ETF** 做成股债组合、或慢慢提高定投额——**先跑通，再放大。**
>
> 如果小 A 自认完全没时间操心，等价的 robo 版本就是：在 **Endowus / Syfe / StashAway**（Topic 67）选一个**中低风险的入门组合**，每月自动定投 S$500，把再平衡也一并托管——**用一点管理费，换「一定能坚持下来」。**

**两个版本的共同点，才是重点**：**极简、分散、金额小、自动化、先跑通再放大。** 标的和平台可以换，这五条原则不变。

## 📝 本篇小结

- **第一个组合的使命不是赚钱，是「用最小代价跑通流程 + 认识自己」**——验证操作链路、测出你真实的风险意愿、照出你的行为偏误、找到适合你的节奏。
- **两条起步路线**：**DIY**（自己买 1–2 只宽基 ETF，费最低、最掌控、需动手）或 **Robo**（托管一个组合，最省心、有额外管理费）。没有绝对优劣，很多人先 robo 养习惯、同时小额 DIY 练手。
- **极简优先**：一只宽基 ETF 内部已帮你分散到全球数千家公司，**一到两只就够**；复杂度应随经验增长，而不是一上来拉满。可从「全股」起步，跑顺后再加债券降波动（Topic 63 雏形）。
- **股债比例联动风险与回报**：股票越多，预期回报越高但波动与坏年份亏损越大；加债券（相关性低）能有效压低波动——这是 Topic 25、59、62 的真实落地。
- **灵魂铁律——金额一定要小**：小到「明天腰斩也睡得着、不影响生活、不会被逼割肉」。因为第一个组合测的是**你自己**，而学费大小完全由金额决定；真正压垮新手的不是跌幅百分比，是**亏损的绝对金额**。
- **避坑五原则**：极简、分散、金额小、自动化、**先跑通再放大**；先打好地基（应急金、清高息债）再进场。

> **下一篇预告（Topic 71）**：🛠️ 建立自动化与「少看盘」机制——组合搭好了，接下来要做的最重要的事，恰恰是**「什么都不做」**。我们会用自动转账、自动定投把情绪彻底挡在门外，并从行为金融的角度解释：**为什么「少看盘」本身就是一种能实实在在提高你长期收益的策略。**
