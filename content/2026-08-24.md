# Topic 69：🛠️ 定投策略（Dollar-Cost Averaging，DCA）——用纪律消除择时风险的原理与具体设置

> 上一课（Topic 68）我们把「开户 → 入金 → 换汇 → 下单」整条链路跑通了。账户开好了，钱也躺进券商了。现在你盯着屏幕，手指悬在「买入」上，脑子里冒出那个让无数新手瘫痪的问题：
>
> **「现在是不是最差的入场时机？万一我一买就跌怎么办？要不要再等等？」**
>
> 这一课要给你的，不是一个「什么时候该买」的答案——因为**没有人能可靠地预知短期涨跌**（这一点 Topic 48 讲市场有效性时就埋下了）。这一课给你的是一套**让你根本不需要回答那个问题**的策略：**定投（DCA）**。
>
> 它用一条极其简单的规则，把「择时」这件几乎注定失败的事，从你的决策里彻底删掉——**每隔固定时间，投入固定金额，不管涨跌，机械执行。** 听起来太简单？别急，我们会用数学证明它为什么真的能压低你的平均成本、用模拟器让你亲眼看到它如何在下跌里「悄悄捡便宜」，也会**诚实地告诉你它的代价**——因为把代价讲清楚，你才知道该在什么场景用它。

---

## 一、先搞懂问题：你真正怕的不是「跌」，是「买在最高点」

先把恐惧说清楚。新手迟迟不敢下单，本质是怕一件事：**把一大笔钱，恰好投在市场的顶部，然后眼睁睁看着它腰斩。**

这种恐惧不是没道理——它真的可能发生。但问题在于，**为了躲开这个「最坏情况」，大多数人付出的代价是「永远不入场」**，而长期不入场，等于把 Topic 3、Topic 4 讲过的**时间价值与复利**整台机器拱手让人。

定投的核心思想，是把「一次性押注一个价格」这件高压决策，**拆散成很多次小额买入，摊在不同的时间点、不同的价格上**。这样一来：

- 你不可能「全部买在最高点」——因为你根本不是一次买完的；
- 你也不可能「全部买在最低点」——但你从来不需要那种运气；
- 你买到的，是这段时间里的一个**平均价格**——而且，正如下一节要证明的，这个平均**天然偏向便宜的一侧**。

> 一句话概括 DCA 的精神：**「我承认我猜不到底部，所以我不猜。我用时间把风险摊平，用纪律把情绪关在门外。」**

---

## 二、DCA 到底是什么——一条规则，两个「固定」

**定投（Dollar-Cost Averaging）** 的定义只有一句话：

> **每隔一个固定的周期（比如每月 1 号），投入一笔固定的金额（比如 S$500），买入同一个目标（比如一只宽基 ETF），不论当时价格高低，机械地重复执行。**

注意这里**固定的是「金额」，不是「份数」**——这是 DCA 全部魔法的来源。因为金额固定，价格高时你**自动买到更少的份数**，价格低时你**自动买到更多的份数**。你不需要判断「现在贵不贵」，这条规则**替你自动做到了「贵时少买、便宜时多买」**。

| 对比 | 固定份数买入（每月买 10 股） | **定投 / 固定金额（每月买 S$500）** |
|---|---|---|
| 价格 S$50 时 | 花 S$500，买 10 股 | 花 S$500，买 **10** 股 |
| 价格 S$25 时（跌了） | 花 S$250，买 10 股 | 花 S$500，买 **20** 股 ← 自动多买 |
| 价格 S$100 时（涨了） | 花 S$1000，买 10 股 | 花 S$500，买 **5** 股 ← 自动少买 |
| 效果 | 越贵花越多，越便宜花越少（反了！） | **越便宜买越多，越贵买越少（对了！）** |

看出来了吗？「固定份数」那一列的行为是**反人性也反逻辑的**——价格越高你投入越多。而 DCA 的「固定金额」规则，**不需要你动任何脑筋，就自动实现了「低买多、高买少」**。这就是它压低平均成本的机械原理。

## 三、数学证明：为什么 DCA 的平均成本，总是 ≤ 价格的平均值

这不是玄学，是可以证明的。定投买到股票的**平均成本**是：

$$\text{平均成本} = \frac{\text{总投入金额}}{\text{总买到份数}}$$

假设你每期都投入相同金额 $A$，在价格 $P_1, P_2, \dots, P_n$ 时各买一次。第 $i$ 期买到的份数是 $A / P_i$。于是：

$$\text{平均成本} = \frac{n \cdot A}{\sum_{i=1}^{n} \dfrac{A}{P_i}} = \frac{n}{\sum_{i=1}^{n} \dfrac{1}{P_i}}$$

右边这个式子，正是价格序列的**调和平均数（harmonic mean）**。而数学上有一条铁律：

$$\text{调和平均} \le \text{算术平均}$$

也就是说：

$$\underbrace{\frac{n}{\sum 1/P_i}}_{\text{你的定投平均成本}} \;\le\; \underbrace{\frac{\sum P_i}{n}}_{\text{这段时间价格的普通平均}}$$

**结论：定投买到的平均成本，永远小于等于「你如果每期买等量份数」所付的平均价格**——只要价格有波动，就是严格小于。价格波动越大，这个「便宜」的幅度越明显。

### 3.1 一个具体的三期例子

假设你连续 3 个月、每月投 S$300，价格分别是 S$30、S$10、S$20：

| 月份 | 投入 | 当月价格 | 买到份数 |
|---|---|---|---|
| 第 1 月 | S$300 | S$30 | 10 股 |
| 第 2 月 | S$300 | S$10 | **30 股** ← 便宜时自动多买 |
| 第 3 月 | S$300 | S$20 | 15 股 |
| 合计 | **S$900** | 均价 (30+10+20)/3 = **S$20** | **55 股** |

- 你的**定投平均成本** = 900 / 55 = **S$16.36 / 股**
- 而这三个月的**价格算术平均** = **S$20 / 股**

**你的平均持仓成本 S$16.36，比价格的平均值 S$20 低了 18%**——你什么都没预测，只是机械地每月投 S$300，就自动买在了「比平均更便宜」的位置。这就是调和平均 ≤ 算术平均在你账户里的真实体现。

## 五、诚实时刻：定投 vs 一次性投入（Lump Sum），谁赢？

网上有一种流行说法：「定投稳赚不赔、比一次性买入更好」。**这是错的，至少不完整。** 我们必须诚实。

先厘清一个常见混淆——这里比的是一个非常具体的场景：**「你手上已经有一大笔现金（比如年终奖、遗产、卖房款），是现在一次性全买，还是分 12 个月慢慢定投？」**

金融界对此有大量研究，其中最著名的是 **Vanguard 的经典研究**，结论很反直觉但很稳健：

> **在大约 2/3 的历史时间窗口里，「一次性投入（Lump Sum）」的最终收益高于「把同一笔钱分批定投」。**

**为什么？** 因为一条基本事实：**市场长期是向上的**（Topic 45 讲过，长期风险溢价为正）。既然大部分时间在涨，那么「让钱尽早、尽多地待在市场里」，平均而言就更划算。分批定投意味着你的钱**平均只有一半时间在市场里工作**，另一半还躺在现金里，错过了上涨——这就是 DCA 的**机会成本**（呼应 Topic 7）。

### 5.1 那……DCA 岂不是没用了？——不，你把「场景」搞混了

关键在于**区分两种完全不同的处境**，别把它们混为一谈：

| 你的处境 | 更优策略 | 为什么 |
|---|---|---|
| **手上已有一大笔闲钱**（奖金、遗产），且你能承受短期波动 | **倾向一次性投入** | 市场长期向上，早入场平均更划算；分批＝主动让一半钱闲置 |
| **每月从工资里挤出一笔钱**（大多数上班族的真实情况） | **DCA 是唯一自然的选择** | 你的钱**本来就是每月一点点到手的**，根本没有「一大笔」可供一次性投——DCA 不是你选的，是现金流的形态决定的 |
| **一次性投入会让你焦虑到失眠、可能中途割肉** | **DCA（作为行为保险）** | 此时 DCA 换取的是「**你能睡着觉、不会在低点恐慌卖出**」——用一点点期望收益，买你的**执行力和情绪稳定** |

**所以 DCA 的真正价值有两层，要分清：**

- **数学层面**：面对一笔已有的现金，DCA 的**期望收益通常略低于**一次性投入（代价：机会成本）。它不是「更会赚钱」的策略。
- **行为 + 现金流层面**：对**绝大多数靠工资定期存钱的普通人**，DCA 根本不是「要不要」的选择题——**你的收入就是分期到手的，定投是与现金流最匹配的方式**。同时，它把「择时」这个几乎必败、又极其消耗情绪的决策**从你的生活里彻底删除**，让你能长期、稳定地留在场内。

> **一句话记住**：**如果你已经有一大笔钱，理论最优往往是「一次性投入」；但如果你像大多数人一样每月存一点，DCA 就是你天然、且最该坚持的方式。DCA 卖的不是「更高收益」，是「更高的执行成功率」——而对普通人来说，能坚持下来的平庸策略，远胜于坚持不了的最优策略。**

    document.getElementById('dcOut').innerHTML = fmt(dcEnd);

    var diff = lsEnd - dcEnd;
    var v = document.getElementById('lsVerdict');
    if (Math.abs(diff) < 30){
      v.innerHTML = '两者几乎打平。';
    } else if (diff > 0){
      v.innerHTML = '🏆 <b>一次性投入胜出 ' + money(diff) + '</b>。因为这段行情整体向上（或早段没深跌），越早把全款投进去、越多时间享受上涨——这就是「市场长期向上，所以早入场更划算」的写照。';
    } else {
      v.innerHTML = '🏆 <b>定投胜出 ' + money(-diff) + '</b>。因为前期深跌，定投在低位自动买到大量便宜份数，反弹时占了大便宜——这正是 DCA 的梦幻场景：<b>先跌后涨</b>。';
    }
  }
  sel.addEventListener('change', update);
  update();
})();
</script>

**切换四种行情，你会亲眼确认第五节的结论：**

- **牛市 / 早段不跌** → **一次性投入赢**（多数历史时间属于此类，故 Vanguard 统计里它平均胜出）。
- **先跌后涨（V 形）** → **定投赢**（低位捡到便宜份数）。
- **一路熊市** → 两者都亏，但**定投亏得少一点**（后面买的更便宜，拉低了平均成本）——这也是 DCA 在下行期的**心理缓冲**价值。

**没有哪一种永远赢。** 选择取决于你是「已有一大笔钱」还是「按月存钱」，以及你的情绪能承受多大波动。把这句话刻进脑子，你就不会再被「定投稳赚」这类半真半假的口号误导。

## 七、🛠️ 怎么设置：把定投变成「自动挡」，让情绪彻底离场

DCA 最大的敌人不是行情，是**你自己**——是在大跌那个月手贱暂停了定投，或在大涨那个月忍不住追加。破解之道只有一个词：**自动化**。把定投设成一台你**不需要每月做决定**的机器（这也正是下一课 Topic 71「自动化与少看盘」的核心）。

一套可落地的设置清单：

1. **定金额，量力而行**：从工资里挤出一笔**就算市场腰斩也不影响生活、不会被逼着卖出**的钱（呼应 Topic 11 应急金要先备好）。宁可少，别中断。
2. **定周期**：每月一次最常见（对齐发薪日）。周期太密（每天）会增加交易/换汇成本却几乎不提升摊平效果；太疏（每季）则钱闲置更久。**每月是性价比甜点。**
3. **定标的**：**一到两只宽基 ETF**（Topic 53–57 讲过的低费率、分散、UCITS 结构），别选一堆个股——DCA 的前提是标的本身**长期向上且不会归零**。**对会退市清零的单一个股做定投，是在给一个可能奔向零的东西持续送钱。**
4. **设成自动**：用券商/robo 的**自动定投（recurring investment）**或银行的**自动转账（GIRO/standing order）**——发薪次日自动扣款、自动买入。**让钱在你还没来得及纠结之前就已经投出去了。**
5. **⚠️ 盯住成本**：每月一次的小额买入，会**放大固定费用的占比**——如果每笔要付固定佣金或高换汇价差，小额定投会被手续费严重侵蚀。优先选**零/低佣金、低 FX 价差、支持自动定投**的平台（呼应 Topic 66、68）。
6. **约法三章：不许暂停**。写下一条给未来自己的规矩：**「无论涨跌，都不手动干预。」** 大跌时最想停的那一刻，恰恰是 DCA 在替你疯狂捡便宜的时候——停了，等于亲手关掉这台机器最赚钱的功能。

> ⚠️ **DCA 不是万能护身符，两条边界要记牢**：
> ① **它不能保证盈利、也不能防止亏损**——如果标的长期下跌不回头，定投只是「用更低的平均成本，亏得慢一点」，不会点石成金（回到模拟器选「一路阴跌到底」看一眼）。
> ② **DCA 是「买入纪律」，不是「卖出策略」**。它解决的是「如何持续、无情绪地入场」；至于何时该再平衡、该不该卖，那是 Topic 65（再平衡）和后续内容的事，别把两者混为一谈。

## 📝 本篇小结

- **DCA 的定义**：固定周期、固定**金额**、机械买入同一标的，不择时。固定的是钱不是份数，于是**自动实现「便宜时多买、贵时少买」**。
- **数学根基**：定投平均成本 = 价格的**调和平均**，而调和平均 **≤ 算术平均**——只要有波动，你的成本就低于「价格均值」，波动越大折扣越明显。
- **诚实的对比**：面对**一笔已有的现金**，历史上约 2/3 时间**一次性投入（Lump Sum）跑赢**分批定投，因为市场长期向上、早入场更划算——DCA 的代价是**机会成本**。
- **DCA 的真正价值**：① 对**按月存钱的普通人**，它与现金流天然匹配，是唯一自然的方式；② 它把「择时」这个必败决策删除，用一点期望收益换来**执行力与情绪稳定**——能坚持的平庸策略胜过坚持不了的最优策略。
- **场景决定策略**：已有一大笔钱且扛得住波动 → 倾向一次性；按月存钱或怕波动到会割肉 → DCA。**没有永远的赢家。**
- **落地设置**：定金额（亏得起）、定周期（每月）、定标的（1–2 只宽基 ETF）、**设自动扣款**、盯**小额定投被固定费用侵蚀**的风险、**立下「不手动暂停」的铁规**。
- **两条边界**：DCA 不保证盈利、不防长期下跌；它是**买入纪律**，不是卖出策略。

> **下一篇预告（Topic 70）**：🛠️ 你的第一个组合——原理和纪律都齐了，现在真刀真枪地搭起你的第一个投资组合。我们会用**1–2 只宽基 ETF 或一个 robo 组合**起步，并反复强调一条新手铁律：**金额一定要小**，先把整套流程和自己的情绪都跑通，再谈放大。
