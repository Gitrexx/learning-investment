# Topic 75：羊群效应（Herding）与 FOMO——追涨杀跌背后是恐惧，不是智慧

> 上一课（Topic 74）我们拔掉了「成本价」这根**私人的锚**。但市场里还有一根锚，比成本价更狡猾、更有传染性——那就是**「别人都在买」**。
>
> 当锚从「一个数字」变成「一群人」，事情就升级了：因为人是**社会动物**，「和大家做一样的事」在我们的大脑里，不是一个可选项，而是一条深植在基因里的**生存指令**。于是当整条街的人都朝一个方向跑时，你会发现自己的腿，不由自主地也跟着迈了出去——哪怕你根本不知道大家在跑什么。
>
> 这一课我们要看清三件事：为什么「跟着大家」在草原上能救命、在市场里却常常致命；那个让你半夜睡不着、生怕错过暴富的 **FOMO**（Fear of Missing Out）到底是什么；以及，羊群是怎么用一个「看似聪明」的机制，把一群理性的人，一个接一个地推下悬崖的。

---

## 一、先回到草原：跟着跑，曾经是最优策略

想象十万年前的一个黄昏，你和族人在草原上觅食。突然，你左边的三个人毫无征兆地撒腿狂奔。这时你有两个选择：

- **选择 A**：停下来，冷静分析——「他们为什么跑？是狮子吗？风声吗？还是看错了？让我先收集证据……」
- **选择 B**：**先跑再说**，边跑边看。

在那个环境里，选 A 的人，平均而言**活不到把孩子养大**。因为如果真有狮子，多花三秒思考就是致命的；而如果是虚惊一场，跟着白跑几步的代价，不过是喘口气。这是一场**极度不对称的赌注**：跟错了，损失很小；不跟而错了，可能就是命。

于是进化替我们做了选择：**看到同类突然一致行动，先跟上，别多想。** 这条指令被刻进了大脑最古老的部分（系统 1），它反应极快、绕过理性、且带着强烈的**情绪推力**——不跟上就浑身难受。这，就是**羊群效应（Herding）**的生物学地基。

> **羊群效应（Herding）**：个体放弃自己独立的判断，转而**模仿群体的行为**，仅仅因为「大家都在这么做」。它不需要任何人下命令，也不需要参与者互相认识——只要每个人都在**参考旁边人的动作**，一致性就会自我强化，像滚雪球一样越滚越大。

关键在于：这条指令**本身不坏**。在信息稀缺、后果致命、且「多数人的方向大概率正确」的环境里，跟随群体是**高效且理性**的。问题在于——**金融市场，恰恰是这条古老指令几乎全面失灵的地方。**

## 二、一个残酷的实验：三条一样长的线，让你怀疑自己的眼睛

1951 年，心理学家所罗门·阿希（Solomon Asch）做了一个后来无比著名的实验。他让一名真受试者，和**七名其实是托儿（演员）**坐在一起，做一道**小学生都不会错**的题：屏幕左边一条基准线，右边三条线 A/B/C，问哪条和基准线一样长。答案**一目了然**。

前几轮，托儿们都答对，气氛正常。但从某一轮开始，**七个托儿众口一词地、自信地说出一个明显错误的答案**（比如基准线明明和 B 一样长，他们都坚定地说是 C）。轮到那名真受试者时——

结果令人脊背发凉：约 **75%** 的受试者，在至少一次测试中，**放弃了自己眼睛看到的事实，跟着群体报出了错误答案**。总体上，受试者有约 **1/3 的关键回答**倒向了错误的群体共识。事后访谈，很多人说：「我其实觉得是 B，但……七个人都说 C，我以为是自己看错了。」

这个实验的杀伤力在于：题目**毫无难度、答案毫无歧义**，群体带来的压力却依然能扭曲一个人对**客观事实**的报告。请记住这句话：

> **在真相模糊、且带着金钱与情绪的市场里，群体压力对你的扭曲，只会比「三条线」的实验强百倍，绝不会更弱。**

## 三、羊群不是「傻」，而是「聪明地走向愚蠢」——信息瀑布

最反直觉的一点是：羊群效应里的每一个人，**单独看都可能是理性的**。经济学家用「**信息瀑布（Information Cascade）**」精准地拆穿了这台机器是怎么运作的。

设想一家新开的餐厅，两条街上各一家，你不知道哪家好。你路过时，看到**甲店排了长队、乙店空空荡荡**。你会怎么想？

> 「这么多人排甲店，他们大概知道些我不知道的——甲店应该更好。」于是你也去排甲店。

注意：你这个决定**看起来完全理性**——你把「别人的选择」当成了一种**信息**。可问题是，排在你前面的每一个人，可能都是**用同样的逻辑**做出的决定：第一个人也许只是随手一指，第二个人看到第一个人排队就跟上，第三个人看到两个人排队更确信……到你这里，队伍已经很长，你几乎不可能不跟。

于是一个惊人的结论出现了：**整条长队，可能建立在第一个人一次随机的、毫无根据的选择之上。** 每个人都理性地「参考前人」，却让一个**微不足道的初始噪音**，被逐级放大成了看似铁证如山的「共识」。这就是信息瀑布——**私人信息被公开行为淹没，人们不再传递自己的判断，只是转发上一个人的判断。**

## 四、FOMO：羊群效应在你身上引爆的那一刻

如果说羊群效应是**机制**，那 **FOMO（Fear of Missing Out，错失恐惧）**就是它在你**个人情绪层面**点燃的那把火。

> **FOMO**：眼看着「别人都在赚钱、都在参与，而我没有」时，那种混合了**焦虑、嫉妒、后悔与紧迫感**的强烈痛苦。它驱使你**放弃原有计划、在高位仓促入场**，只为了「不被落下」。

请注意 FOMO 的情绪配方里，**主料是「恐惧」，不是「贪婪」**。表面看，追高的人像是贪心；但驱动他们的，其实是一种更原始的痛苦——**害怕被群体抛下、害怕自己是唯一没搭上车的那个傻瓜**。这正是草原本能的现代变体：**十万年前怕被狮子吃掉，今天怕被暴富的群体落下。** 两者调用的是**同一套神经回路**。

FOMO 的典型剧本，几乎每一轮泡沫都在重演：

1. **某个资产开始猛涨**（互联网股票、比特币、某只 meme 股、某个热门基金）。
2. **媒体与社交网络开始刷屏**：邻居、同事、群里的人都在晒收益。信息瀑布启动。
3. **「再不上车就来不及了」的紧迫感**淹没理性。你忘了估值、忘了风险，只剩一个念头：买。
4. **你在接近顶部时入场**——恰恰是风险最高、赔率最差的时刻。
5. 音乐停止，瀑布反向。**最后进场的人，接下了最重的一棒。**

这套剧本之所以永不过时，是因为它利用的不是你的知识漏洞，而是你的**生理本能**。你越是眼睁睁看着别人「轻松暴富」，那份痛苦就越真实——而痛苦，是最好的行动催化剂。

## 五、追涨杀跌的数学代价：情绪如何吃掉你的收益

羊群与 FOMO 的最终产物，是散户最经典的死亡循环——**追涨杀跌（buy high, sell low）**：在群体最狂热（价格最高）时因 FOMO 冲进去，在群体最恐慌（价格最低）时因恐惧割肉出来。这在方向上，**和赚钱的唯一正道（低买高卖）完全相反。**

这不是一句道德训诫，而是一个**可以量化的黑洞**。业内有一个著名指标叫「**行为差距（Behavior Gap）**」：它衡量**基金本身的收益率**，与**这只基金里普通投资者实际拿到的收益率**之间的差。研究（如 Morningstar 的「Mind the Gap」年度报告、以及早年 Dalbar 的投资者行为研究）反复发现：由于投资者总在**高点申购、低点赎回**，他们**实际到手的回报，通常每年比基金本身低 1%~3% 甚至更多**。

一只基金十年翻倍，基民却可能只赚了一半——**差的那部分，就是被追涨杀跌的择时冲动吃掉的。** 下面这个模拟，让你亲眼看到这个黑洞有多大。

  // A price path over 12 months: rise, peak, crash, partial recovery. Ends roughly flat-to-up.
  var prices=[100,112,126,140,150,138,120,104,96,108,120,130];
  function draw(){
    var emo=Number(fomoR.value); fomoLbl.textContent=emo.toFixed(2);
    var months=prices.length;
    var monthly=100; // baseline monthly budget
    // 1) Disciplined DCA: invest fixed 100 each month
    var dcaUnits=0, dcaCost=0;
    for(var i=0;i<months;i++){ dcaUnits+=monthly/prices[i]; dcaCost+=monthly; }
    // 2) Buy & hold: put all 12*100 in at month 0
    var bhUnits=(monthly*months)/prices[0], bhCost=monthly*months;
    // 3) FOMO: base 100/mo, but scaled by recent momentum. Buys MORE after gains, LESS/sells after drops.
    var fomoUnits=0, fomoCost=0, fomoCash=0;
    for(var j=0;j<months;j++){
      var mom = j===0 ? 0 : (prices[j]-prices[j-1])/prices[j-1]; // recent return
      // multiplier: >1 when rising (chase), <1 or negative (panic sell) when falling
      var mult = 1 + emo*(mom*6);
      var invest = monthly*mult;
      if(invest>=0){ fomoUnits+=invest/prices[j]; fomoCost+=invest; }
      else {
        // panic sell: liquidate |invest| worth of units at current low price
        var sellVal=Math.min(-invest, fomoUnits*prices[j]);
        fomoUnits-=sellVal/prices[j]; fomoCash+=sellVal; fomoCost+=monthly; // still "committed" the monthly budget
      }
    }
    var last=prices[months-1];

## 六、如何不做那只羊：5 条反 FOMO 工具

羊群本能无法被「删除」（它写在基因里），但可以被**规则和结构**制服。核心思路只有一句：**用事先定好的纪律，替换掉临场的情绪。**

1. **先有计划，后有行情。** 在市场平静、你头脑清醒时，就把你的资产配置、定投金额、买卖纪律**白纸黑字写下来**（呼应 Topic 69 的 DCA 与后面 Topic 81 的「防呆机制」）。当 FOMO 来袭时，你要做的不是「决策」，而是**执行早已写好的剧本**——因为身处狂热中的你，是最不该被信任的决策者。

2. **把「自动化」当护城河。** 设置**自动定投**（Topic 71）。自动扣款的美妙之处在于：它在你**没有情绪**的时候，替情绪中的你做了正确的事。机器不会 FOMO，也不会恐慌割肉。

3. **给冲动装一个「冷静期」。** 给自己立一条规矩：**任何计划外的买卖，必须等 48 小时再执行。** FOMO 的本质是「紧迫感」——而几乎所有真正的好机会，都不会因为你多想两天就消失；反之，那些「再不上车就没了」的，往往正是最该躲开的。**紧迫感本身，就是危险信号**（呼应 Topic 18、20 对诈骗话术的拆解）。

4. **主动问「谁在卖给我？」和「共识里定价了吗？」。** 当所有人都在买、消息面一片欢腾时，请冷静地想：**价格是不是已经把这份乐观全部计入了？** 你听到的「利好」，早已是**旧闻**，早已反映在价格里（呼应 Topic 48 有效市场）。真正的便宜货，诞生于**无人问津、甚至人人喊打**的角落，而不是人声鼎沸的排队长龙里。

5. **记住巴菲特那句被说滥、却真正有用的话：「别人贪婪时我恐惧，别人恐惧时我贪婪。」** 它之所以难，恰恰是因为它要求你**逆着十万年的进化本能行事**。你不需要做一个极端的逆向投资者，但至少要训练自己：当强烈的 FOMO 涌上来时，把它**当成一个「该踩刹车」的信号，而不是「该踩油门」的信号。**

## 📝 本篇小结

- **羊群效应（Herding）** 是一条深植基因的**生存指令**：在信息稀缺、后果致命的草原上，「看到同类一致行动就先跟上」曾是理性且高效的。但在**真相模糊、价格由未来现金流决定**的金融市场，这条古老指令几乎全面失灵。
- **阿希实验**证明：即便面对答案一目了然的问题，约 75% 的人也会在群体压力下至少一次放弃自己的判断。市场里的压力只会更强。
- **信息瀑布（Information Cascade）** 揭示了羊群「聪明地走向愚蠢」的机制：每个人都理性地把「别人的行为」当信息、放弃自己的私人线索，结果让一个**微小的初始噪音**被放大成看似铁证的「共识」——它极其脆弱，遇到反向信号会瞬间掉头。
- **FOMO** 是羊群效应在个人身上的引爆点，其情绪主料是**恐惧**（怕被群体抛下），不是贪婪。它驱使人在**高位仓促入场**，接下最后一棒。
- **追涨杀跌**的代价可量化为「**行为差距**」：投资者因高买低卖，实际收益通常每年比其所持基金本身低 1%~3%。**机构抱团（职业安全动机）会放大而非消除**这种羊群。
- **反 FOMO 五工具**：先有计划后有行情；用自动化当护城河；给冲动装 48 小时冷静期；主动问「共识是否已被定价」；把强烈的 FOMO 当作**踩刹车**而非踩油门的信号。

**下一课预告 · Topic 76：过度自信（Overconfidence）——你没有自己以为的那么聪明**。跟完了群体，我们再来照照镜子：为什么绝大多数人都觉得自己的判断「高于平均」，而这份自信，恰恰是账户最隐蔽的杀手。
