## 一、为什么要自动化？——因为你最大的敌人，是「未来的你」

先想清楚一个残酷的事实：**一个投资计划会失败，绝大多数时候不是因为策略错了，而是因为「人」没执行下去。**

你在 Topic 69 学会了定投（DCA），道理你全懂：每月固定投一笔，用纪律消除择时。但「每月手动投一笔」这件事，真正要对抗的是什么？

- **对抗遗忘**：这个月太忙，忘了投；下个月又忘了。
- **对抗情绪**：市场大跌，账户飘绿，你心里发慌——「要不这个月先别投了，等跌稳了再说」（结果一等就等过了最该买的低点）。市场大涨，你又觉得「太贵了，等回调再投」（结果一路踏空）。
- **对抗惰性与诱惑**：这个月想换新手机，那笔钱先挪去消费吧，投资的事下个月补——然后就再也没补。

**每一次「手动投」，都是一次意志力的考验。而意志力是一种会枯竭的稀缺资源。** 你不可能连续几十年、每个月都战胜遗忘、情绪和诱惑。只要有几次没扛住，你的定投计划就出现了缺口——而缺的往往正是市场最恐慌、最该买的那几个月。

自动化的核心思想只有一句话：

> **把「需要靠意志力反复做出的正确决定」，变成「一次性设置好、之后自动发生的默认动作」。**

你只需要在**理智清醒的此刻**做一次决定（「每月发薪后自动投 S$500」），然后让系统在**未来每一个你可能动摇的时刻**替你执行。**你把自己从决策回路里移了出去——而你，恰恰是这个系统里最不稳定的一环。**

## 二、「先付给自己」（Pay Yourself First）——自动化的灵魂顺序

自动化不只是「设个自动扣款」这么简单，它背后是一个能彻底改变你财富轨迹的顺序调换。

**大多数人的现金流顺序是这样的：**

$$\text{收入} \;\to\; \text{花销（房租、吃饭、娱乐、购物）} \;\to\; \text{月底剩下的} \;\to\; \text{（也许）拿去投资}$$

这个顺序有个致命缺陷：**「投资」排在了最后，用的是「花剩下的钱」。** 而人性决定了——**花销会自动膨胀到把收入填满**（这叫帕金森花钱定律：钱有多少就能花掉多少）。于是「月底剩下的」永远接近于零，投资永远「等有余钱再说」。

**「先付给自己」把这个顺序倒过来：**

$$\text{收入} \;\to\; \underbrace{\text{自动划走一笔去投资}}_{\text{先付给「未来的自己」}} \;\to\; \text{剩下的才是可花的钱}$$

**关键就在「先」和「自动」这两个字。** 发薪日一到，那笔投资款在你还没来得及看见、还没来得及产生「拿这钱去买点什么」的念头之前，就已经被自动划走了。你剩下的余额，才是你这个月真正可以花的钱——**你会自然而然地把生活开销压缩进这个余额里，而完全感觉不到「痛」。**

> 💡 **这就是自动化最神奇的地方**：它不是靠「省」——靠省是痛苦的、需要意志力的、会反弹的；它是靠**「让你根本看不到那笔钱」**。看不到，就不会去花；不去花，就自动存下来投资了。储蓄和投资，从一件「需要克制」的苦差事，变成了一件「自动发生、无需感知」的背景进程。

## 四、少看盘：为什么「不看」本身就是一种能提高收益的策略

自动化解决了「持续投入」的问题。但还有半个魔鬼没被降服——**你会忍不住去看**。而「看」本身，就是引发「手贱操作」的第一张多米诺骨牌。

这里有一个被行为金融学反复证实、却极其反直觉的结论：

> **你查看账户越频繁，你「感受到的痛苦」越多，你做出错误操作的概率越大——最终，看得越勤，往往赚得越少。**

为什么？这背后是一个叫**「短视损失厌恶」（Myopic Loss Aversion）**的机制，由行为经济学家 Benartzi 和 Thaler 提出，它把两件事叠加在了一起：

1. **损失厌恶（Topic 73 会细讲）**：亏 100 元的痛，约是赚 100 元快乐的 **2.5 倍**。人对亏损的敏感度远高于盈利。
2. **短视（看得太频繁）**：你查看得越频繁，看到的时间窗口就越短；而**在越短的窗口里，市场看起来越像「随机的红绿闪烁」——涨跌几乎五五开。**

把这两点乘起来，结论就出来了：**你每天看盘，就等于每天都要经历一次接近 50% 概率的「见红」，每次见红都被放大 2.5 倍的痛。** 长期看，市场是上涨的（Topic 45），但**在日线级别的短窗口里，上涨的趋势被巨大的短期噪声淹没了**——你看到的不是「长期向上的曲线」，而是「今天绿了、明天红了」的心电图。

**这种高频的痛感会驱动你做傻事**：跌了想「割肉止损」，涨了想「落袋为安」，看到一条新闻就想调仓。**而每一次这样的操作，都在偏离你当初理智制定的计划。** 反过来，一个**季度、甚至一年才看一次**的人，看到的是被时间「熨平」了的、大概率上涨的画面——他心态平和，什么都不用做，反而稳稳吃到了市场的长期回报。

> 📖 **一个流传甚广的说法**：据称富达（Fidelity）内部曾做过一项统计，发现表现最好的账户，往往属于两类人——**「忘了自己还有这个账户的人」，以及「已经过世的人」。** 这个故事的真实性难以严格考证，但它精准地道出了一个真相：**在长期投资里，「什么都不做」的人，常常跑赢了「勤奋操作」的人。** 你的双手，往往是你账户最大的敌人。

学术证据也一致：一项对散户的经典研究（Barber & Odean）发现，**交易最频繁的那批散户，扣除成本后的净收益显著低于「买了就放着不动」的人**——手越勤，赚得越少。

(function(){
  var freqSel = document.getElementById('freqSel');
  if(!freqSel) return;
  var muR = document.getElementById('muR'), sgR = document.getElementById('sgR');

  // 标准正态 CDF（Abramowitz-Stegun 近似 erf）
  function normCdf(x){
    var t = 1/(1+0.2316419*Math.abs(x));
    var d = 0.3989422804014327*Math.exp(-x*x/2);
    var p = d*t*(0.31938153 + t*(-0.356563782 + t*(1.781477937 + t*(-1.821255978 + t*1.330274429))));
    return x >= 0 ? 1-p : p;
  }

  function update(){
    var t = +freqSel.value;            // 单个窗口的年数
    var mu = +muR.value/100, sg = +sgR.value/100;
    document.getElementById('muLbl').textContent = (mu*100).toFixed(1);
    document.getElementById('sgLbl').textContent = (sg*100).toFixed(0);

    // 该窗口内收益 ~ N(mu*t, (sg*sqrt(t))^2)；P(亏损)=Φ(-mu*sqrt(t)/sg)
    var z = -mu*Math.sqrt(t)/sg;
    var pRed = normCdf(z);
    var perYear = 1/t;                 // 一年看几次
    var painfulViews = pRed*perYear;   // 一年里大约见红几次

    document.getElementById('redOut').innerHTML =
      '<span style="color:#d9534f">' + (pRed*100).toFixed(0) + '%</span>';
    document.getElementById('cntOut').innerHTML =
      '约 <b>' + (painfulViews < 1 ? painfulViews.toFixed(1) : Math.round(painfulViews)) + '</b> 次';

    var v = document.getElementById('freqVerdict');
    if (t <= 0.02)
      v.innerHTML = '🔴 <b>高频看盘</b>：几乎每次打开都有约一半概率见红，一年被「刺痛」上百次。每一次痛都被损失厌恶放大 2.5 倍，你会一次次想「要不要卖了保本」——<b>这正是把长期投资者变成短线韭菜的机制。</b>';
    else if (t <= 0.1)
      v.innerHTML = '🟠 <b>每月/每周看</b>：见红概率仍然不低，短期噪声盖过了长期趋势。你看到的是「心电图」，不是「上坡路」——情绪很容易被牵着走。';
    else if (t < 1)
      v.innerHTML = '🟡 <b>每季度看</b>：拉长窗口后，上涨的趋势开始盖过噪声，见红概率明显下降，心态平和很多。查看频率降到「季度对账」级别，已经足够。';
    else
      v.innerHTML = '🟢 <b>每年甚至更久才看</b>：时间把短期噪声熨平了，你看到的大概率是一条上涨的曲线。见红概率低，几乎没有「手贱」的冲动——<b>这就是「少看盘」能实实在在提高收益的数学原因。</b>';
  }
  freqSel.addEventListener('change', update);
  muR.addEventListener('input', update);
  sgR.addEventListener('input', update);
  update();
})();
</script>

**把「查看频率」从「每年」一路切到「每天」，盯着「见红概率」这个数字往上爬：**

- **同一个必然上涨的组合，你每天看，见红概率接近 50%；你每年看，见红概率可能只有二三十%。** 市场没变，变的只是你**观察它的时间窗口**——窗口越短，你看到的越接近「随机噪声」，越容易被吓到。
- **把波动率滑块拉大**（比如全股组合的 16% → 25%），见红概率进一步上升——**波动越大的组合，越经不起频繁看**，越要靠「少看」来保护自己的情绪。
- **这就是「少看盘」的硬核逻辑**：它不是「鸵鸟心态、逃避现实」，而是**主动减少那些会诱发你做出错误操作的「痛感刺激」**。你看得越少，被短期噪声干扰的机会越少，就越能安安静静地拿住、吃到市场的长期回报。

## 六、🛠️ 落地：在新加坡把「自动化 + 少看盘」搭起来

原理讲透了，现在是纯操作。目标是搭一条**「发薪 → 自动到投资账户 → 自动买入 → 你几乎不用管」**的流水线。

**第 1 步 · 自动转账（把钱自动挪到位）**
- 在你的银行 App 里设一个**每月定期转账 / GIRO / Standing Instruction**，时间定在**发薪日的次日**（趁钱刚到、还没花）。让它自动把那笔投资款从你的日常账户，转到你的券商 / robo 入金账户。
- 核心是**「先划走」**：让投资款在你看见余额之前就离开日常账户，落实上面第二节的「先付给自己」。

**第 2 步 · 自动定投（把钱自动买成资产）**
- **Robo（最省心）**：Endowus / Syfe / StashAway 等都内置**自动定投**——设好每月金额和风险组合，它会自动扣款、自动买入、自动再平衡、自动分红再投资。**几乎是「全托管的自动驾驶」，最适合想彻底不操心的人。**
- **券商的定投计划（RSP，Regular Savings Plan）**：很多平台支持对指定 ETF / 基金设**每月自动买入**（例如 FSMOne 的 RSP、部分银行的 Invest-Saver 类产品等）。设好之后，每月自动用固定金额买入你选的宽基 ETF（Topic 57 的 UCITS ETF），把 Topic 69 的 DCA 完全自动化。
- **DIY 手动补位**：若你的标的（如 IBKR 上的某只 UCITS ETF）没有全自动 RSP，退而求其次——设好日历提醒，每月发薪后**花五分钟手动下一单**。虽不如全自动，但只要固定动作、不择时，也能逼近自动化的效果。

**第 3 步 · 主动「少看盘」（把情绪从源头掐断）**
- **删掉 / 藏起看盘 App 的主屏图标**，关掉每日行情推送通知——减少「随手一看」的触发点。
- **给自己定一个「对账节奏」**：例如**每季度**才正式打开看一次，做的唯一动作是「检查自动扣款是否正常、要不要按计划再平衡（Topic 65）」，看完就关。**平时市场再怎么惊天动地，都不看、不动。**
- **约法三章**：把「除非到了预定的再平衡时点，否则绝不手动买卖」写下来，贴在能看到的地方。**你要防的，就是那个未来某天心血来潮想「操作一下」的自己。**

> 🎯 **一句话总结这套系统**：**钱自动进来、自动买成资产，而你主动把眼睛移开。** 你把「坚持」交给了机器，把「不手贱」交给了「看不见」。剩下要做的，就是让时间和复利去工作。

---

## 七、常见误区（照着避坑）

- **❌ 设了自动定投，却还是每天盯盘** → ✅ 自动化管住了「手」的一半，另一半（「眼睛」）要靠主动少看盘管住。两者缺一不可。
- **❌ 把投资款排在「月底花剩的」** → ✅ 一定要「先付给自己」——发薪次日就自动划走，剩下的才是可花的。
- **❌ 一大跌就手动暂停 / 取消自动定投** → ✅ 下跌恰是 DCA 自动帮你捡便宜的时候（Topic 69）。**自动化的价值，正是在你最想中断时替你坚持。**
- **❌「少看盘」= 从此完全不管、连再平衡也不做** → ✅ 少看 ≠ 不管。仍要按预定节奏（如每年）检查一次、必要时再平衡（Topic 65）。是**减少无谓的频繁查看**，不是彻底撒手不问。
- **❌ 自动扣款设好就以为万事大吉，从不核对** → ✅ 每隔一段（如每季度）确认一次自动扣款、买入是否真的成功执行了，别让一个悄悄失败的扣款毁了你的定投链条。
- **❌ 把「少看盘」当成逃避** → ✅ 它是**基于数学（短视损失厌恶）的主动策略**，目的是保护你的情绪、防止手贱，从而提高长期收益——是纪律，不是鸵鸟。

## 📝 本篇小结

- **自动化的本质**：把「需要靠意志力反复做出的正确决定」，变成「一次性设置、之后自动发生的默认动作」——因为你（未来会遗忘、会情绪化、会被诱惑的自己）才是投资系统里最不稳定的一环。
- **先付给自己（Pay Yourself First）**：把现金流顺序从「收入→花销→剩下的才投资」倒成「收入→先自动划走投资→剩下的才可花」。靠的不是「省」，而是**让你根本看不到那笔钱**，于是不会去花。
- **少看盘是一种能提高收益的主动策略**：因为**短视损失厌恶**——看得越频繁，窗口越短，见红概率越接近 50%，而每次见红的痛被放大 2.5 倍，驱使你做出割肉、追涨等错误操作。拉长查看窗口，短期噪声被时间熨平，你才看得到长期向上的趋势、才拿得住。
- **落地三步（新加坡）**：① 自动转账（GIRO / Standing Instruction，发薪次日先划走）；② 自动定投（robo 的自动扣款，或券商 RSP，把 DCA 全自动化）；③ 主动少看盘（藏 App、关推送、只按季度/年对账，约法三章不手动乱动）。
- **一句话**：**钱自动进来、自动买成资产，而你主动把眼睛移开。** 把「坚持」交给机器，把「不手贱」交给「看不见」，剩下的交给时间和复利。

> **下一篇预告（Topic 72）**：为什么人类天生不擅长投资——我们即将进入**行为金融学**模块。这一课解释了一个根本冲突：让我们祖先在草原上活下来的那些本能（对威胁的高度警觉、随大流、快速反应），恰恰是让我们在金融市场里频频犯错的元凶。**看懂了「为什么天生不擅长」，你才知道前面这些「自动化、少看盘」的制度，到底在对抗什么。**
