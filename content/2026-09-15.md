# Topic 91：读财报（二）：利润表——公司到底赚不赚钱

> 上一课（Topic 90）我们读的是**照片**：资产负债表拍下某一时点公司「有什么、欠谁的」。这一课换成**录像**：利润表（Income Statement / Profit & Loss / 损益表）记录的是**一段时间里，公司做了多少生意、花了多少代价、最后剩下多少**。
>
> 它是三张表里**最出名**的一张。每一条「XX 公司第三季度净利同比增长 32%」的新闻，引用的都是它；每一次财报电话会上被反复念叨的 EPS，来自它的最后一行。
>
> 但它也是三张表里**最脆弱**的一张。原因只有一句话：
>
> > **利润表不是数出来的，是「判断」出来的。**
>
> 资产负债表上的现金，你可以去银行对账；利润表上的「收入」和「费用」，则大量依赖会计判断——这笔生意算不算完成了？这台机器该用几年折旧？这笔坏账该提多少？**判断有区间，区间就是空间，空间就是利润可以被合法地调来调去的地方。**
>
> ---
>
> 这不是说利润表没用——恰恰相反，**它是唯一一张试图回答「这门生意本身赚不赚钱」的表**。现金流量表更诚实，但它把「买了一栋楼」和「今年亏损」混在同一个数字里；只有利润表会把楼的成本摊到三十年，告诉你这一年的**经营成果**。
>
> 所以对它的正确姿势不是不信，而是：**知道每一行是怎么来的、有多大的弹性、以及该拿哪张表去校验它。**
>
> 本课分八节、五个互动组件。读完你应该能做到：拿到一份利润表，**说出它每一层的经济含义、指出其中三处最有弹性的假设、并用一个比率快速判断这份利润的「成色」**。

## 一、利润表的骨架：一道从收入滑到归母净利的瀑布

### 1.1 阶梯：每一层都在回答一个不同的问题

利润表本质上是一道**减法瀑布**。很多人读它只看头（收入）和尾（净利），中间几层被略过——而**每一层的差额，恰恰是在回答一个完全不同的问题**：

| 层级 | 算法 | 它回答的问题 | 主要受什么影响 |
|---|---|---|---|
| **营业收入**（Revenue / Turnover） | — | 这段时间做了多少生意 | 需求、定价、确认政策 |
| **− 营业成本（COGS）** | | | |
| **= 毛利（Gross Profit）** | 收入 − 直接成本 | **这门生意有没有定价权** | 商业模式、护城河（Topic 95） |
| **− 销售/管理/研发费用（SG&A、R&D）** | | | |
| **= 营业利润 / EBIT** | 毛利 − 经营费用 | **把公司整体运转起来后，经营本身赚不赚钱** | 经营效率、规模效应 |
| **± 利息、汇兑、投资收益等** | | | |
| **= 税前利润（Pre-tax / EBT）** | EBIT ± 非经营损益 | **加上资本结构的影响后剩多少** | 杠杆（Topic 87）、一次性损益 |
| **− 所得税** | | | |
| **= 净利润（Net Profit）** | 税前 × (1 − 有效税率) | **交完税剩多少** | 税率、税收优惠、递延税 |
| **− 非控制性权益** | | | |
| **= 归属母公司股东净利润** | | **真正属于你这个股东的部分** | 子公司持股比例 |
| **÷ 加权平均股数** | | | |
| **= 每股收益（EPS）** | | **摊到你手里的一股上是多少** | 增发、回购、期权稀释 |

> 🎯 **本节最该记住的一句：投资者真正该盯的是「营业利润（EBIT）」这一层，而不是净利润。**
>
> 净利润底下混了三样与**生意本身无关**的东西：**利息**（你怎么融资的）、**税**（你在哪注册的）、**一次性损益**（卖了栋楼、打了场官司）。同样一门生意，换个资本结构、换个注册地，净利润可以差出一大截，而**它每天在做的事情一模一样**。
>
> 这也是 Topic 89 里 ROIC 用 **NOPAT（= EBIT × (1 − 税率)）**、而不是净利润做分子的原因——**ROIC 要衡量的是「生意的赚钱能力」，不是「老板的融资技巧」。**

### 1.2 一个必须先建立的区分：经常性 vs 非经常性

利润表里的每一行，都要先过一道筛子：**这件事明年还会发生吗？**

- **经常性（recurring）**：卖货、发工资、付租金——这些构成了「**盈利能力（earnings power）**」，是估值时可以外推的部分；
- **非经常性（non-recurring）**：卖掉一栋楼的收益、一笔诉讼赔偿、一次资产减值——**它们影响今年的净利润，但不改变这门生意的长期赚钱能力。**

估值的本质是给**未来的现金流**定价（Topic 89），所以：**一次性收益不该被乘以 PE 倍数，一次性损失也不该被乘以 PE 倍数。**

> 📌 这条原则会在第五节被反过来用一次：公司自己也知道这个道理，于是**「把坏消息说成一次性、把好消息说成经常性」**成了 non-GAAP 报表最常见的动作。你的工作是自己重新分类，而不是接受管理层的分类。

## 二、最上面那一行最难：收入确认

### 2.1 权责发生制：利润表的原罪，也是它的价值

利润表用的是**权责发生制（accrual basis）**，不是收付实现制（cash basis）：

> **收入在「赚到」的时候确认，而不是在「收到钱」的时候确认；费用在「发生」的时候确认，而不是在「付钱」的时候确认。**

为什么要这么麻烦？因为如果按收钱记账，一家 12 月 28 日签了大合同、1 月 3 日才收款的公司，会显得 12 月一分钱没赚——**这明显不符合经济现实**。权责发生制的目的，正是让利润表反映「这段时间的经营成果」，而不是「这段时间的银行流水」。

代价是：**「赚到了」是一个需要判断的事件。** 而任何需要判断的地方，都会有人在判断的边缘做文章。

> 记住 Topic 90 互动一里的那笔业务：**成本 20 的货赊销 35，利润表立刻多了 15 的利润，现金一分没进来。** 这不是造假，这是权责发生制的正常运作。但同一台机器，稍微推一推，就能变成造假。

### 2.2 IFRS 15 的五步法：判断「赚到了没有」的标准流程

2018 年生效的 **IFRS 15 / ASC 606** 统一了全球的收入确认框架，核心是五步：

| 步骤 | 内容 | 争议点在哪 |
|---|---|---|
| **1. 识别合同** | 与客户之间可执行的权利义务 | 收款可能性存疑的合同不该确认 |
| **2. 识别履约义务** | 合同里承诺了几件**可区分**的事 | 硬件 + 三年服务算一件还是两件？拆分方式直接决定确认节奏 |
| **3. 确定交易价格** | 含可变对价（返利、折扣、罚款） | 可变对价的估计需要**判断**，这里弹性最大 |
| **4. 分摊价格到各义务** | 按各自的**单独售价**比例分摊 | 打包销售中把更多价格分给「先交付」的部分，可以提前确认收入 |
| **5. 在履约时确认收入** | 控制权转移给客户时确认 | 「控制权」何时转移，同样是判断 |

**核心判据是「控制权（control）转移」**，不是「风险报酬转移」（这是旧准则 IAS 18 的说法），也不是「发货」或「开票」。

### 2.3 时点确认 vs 时段确认：同一笔钱，节奏可以差好几个季度

- **时点确认（point in time）**：卖一台手机，交货那一刻确认全部收入；
- **时段确认（over time）**：三年的软件订阅，按月摊；一栋楼的建造合同，按完工百分比确认。

**时段确认里藏着最经典的操纵空间**：完工百分比法（percentage-of-completion）要求管理层估计「工程干了几成」——这个估计没有客观读数。

> **东芝（Toshiba）2015 年的会计丑闻**正是这条：在基础设施等业务上通过低估合同成本、操纵完工进度，在约七年里累计虚增税前利润超过 1,500 亿日元，最终导致社长与两任前社长辞职。**没有一笔假发票，全部是「估计」。**

反过来，订阅制的**时段确认**是一种非常健康的结构：客户先付一年费用，公司确认为**合同负债（递延收入）**——Topic 90 说过，这是全表最被低估的一行——然后逐月转成收入。**收入的确定性极高，因为它已经躺在负债栏里了。**

### 2.4 总额法 vs 净额法：GMV 不是收入

一个平台撮合了 100 元的交易，抽佣 8 元。它的收入是 **100** 还是 **8**？

IFRS 15 的判据是**主要责任人（principal）还是代理人（agent）**：

- 若平台**控制**了商品/服务再转售（承担存货风险、自主定价、对履约负主要责任）→ **总额法**，收入 100，成本 92；
- 若平台只是撮合 → **净额法**，收入 8。

两种记法**净利润完全相同**，但收入规模差 12.5 倍，毛利率从 8% 变成 100%。

> 📌 **实操含义：** 看到一家平台/电商/旅游公司「收入暴增」时，先确认口径有没有变过。同理，**GMV、交易额、订单额都不是收入**——它们是公司选择披露的运营指标，没有会计准则约束，**不可与别家的同名指标直接比较**。

### 2.5 四种经典的收入操纵，与它们在报表上的指纹

| 手法 | 具体做法 | 留下的痕迹 |
|---|---|---|
| **压货（channel stuffing）** | 季末给经销商极长账期或高返利，把货压出去确认收入 | **应收账款增速远超收入增速**；下一季度收入塌陷；退货率上升 |
| **提前确认 / bill-and-hold** | 货没发出，以「客户要求代为保管」为由确认收入 | 存货与应收同时异常；附注里出现代管安排（Sunbeam 1998 的手法） |
| **虚构交易** | 通过关联方或空壳公司制造假订单 | 应收账款回收极慢、客户集中度突然上升、毛利率异常平滑 |
| **口径变更** | 把净额法悄悄改成总额法 | 收入跳增而**净利润没变**；附注里的会计政策变更说明 |

> **瑞幸咖啡（Luckin Coffee，2020）** 是最近一次教科书级案例：SEC 认定其在 2019 年 4 月至 2020 年 1 月间，通过关联方虚构了**超过 3 亿美元**的零售交易，2019 年二季度收入虚增约 **28%**、三季度约 **45%**；为掩盖，还同步虚增了超过 1.9 亿美元的费用。2020 年 12 月，瑞幸与 SEC 达成和解，缴纳 **1.8 亿美元**罚款。
>
> 值得注意的是**它为什么要同时虚增费用**：因为**假收入不会带来真现金**。如果只增收入不增费用，账上会凭空出现一大笔收不回来的应收账款，或者利润与现金流的缺口大到无法解释。**造假者最难伪造的，永远是现金。** 这正是第七节要建立的检验方法，也是 Topic 92 的全部意义。

## 三、中间那一段的自由裁量：成本、费用与几个关键假设

收入之下的每一层，都有合法的判断空间。这一节挑出四个**影响最大、最常被使用**的。

### 3.1 COGS 与费用之间的那条线，是可以挪的

哪些成本算「营业成本」，哪些算「销售管理费用」，准则给了原则但没有给逐项清单。把运费、客服成本、部分工厂管理费在两栏之间挪一挪：

- **毛利率上升了**，故事更好听（「我们的毛利率提升到了 60%」）；
- **营业利润一分没变**。

> 📌 **所以毛利率的横向比较必须小心，纵向比较（同一家公司的时间序列）要留意口径变更。** 一个万能的交叉验证：**毛利率大幅改善、但营业利润率纹丝不动，通常意味着只是搬了个家。**

### 3.2 折旧年限：一个假设，三十亿利润

$$\text{年折旧} = \frac{\text{资产原值} - \text{残值}}{\text{预计使用年限}}$$

分母是**估计值**。把它从 4 年改成 6 年，年折旧立刻降低三分之一，而**公司什么都没做**。

这不是理论。两个公开披露的真实案例：

- **微软**在 2022 年宣布，自 **FY2023** 起将服务器与网络设备的折旧年限**从 4 年延长至 6 年**。按 2022 年 6 月 30 日的资产账面额计，这一会计估计变更使 FY2023 的**营业利润增加约 37 亿美元、净利润增加约 30 亿美元（约合每股 0.40 美元）**。
- **Alphabet** 在 2023 年 1 月宣布服务器折旧年限**从 4 年延长至 6 年**、部分网络设备从 5 年延长至 6 年；公司当时预计 2023 全年折旧费用减少约 **34 亿美元**，实际全年折旧减少约 **39 亿美元**、净利润增加约 **30 亿美元**。

两家公司都在财报里**清楚披露了**这件事——这是合规的会计估计变更，不是造假。但对读表的人来说，含义非常直接：

> 🎯 **那一年的「利润增长」里，有几十亿美元不是赚来的，是假设改出来的。而经营现金流一分钱都没有因此变化。**

**判断是否合理，要看经济实质**：服务器确实因为软件效率提升而用得更久了吗？还是只是需要一个更好看的季度？前者合理，后者是**利润管理（earnings management）**。可靠的做法是去看同行：如果全行业都在延长，多半是技术趋势；如果只有一家在延长、且恰好在增长失速的那一年，就该警觉。

### 3.3 研发：费用化还是资本化

- **费用化**：当期全部计入费用，利润立刻减少；
- **资本化**：先记为无形资产，再分几年摊销，当期利润更好看。

准则的态度（Topic 90 提过）：**IAS 38 下，研究（research）阶段必须费用化，开发（development）阶段只有满足六项严格条件才可资本化；US GAAP 则更严——研发原则上全部费用化**（软件开发在达到技术可行性后有有限例外）。

这就产生一个**极重要但反直觉**的结论：

> **对同样的两家公司，会计上更「保守」（全部费用化）的那家，报表利润更难看，但真实价值可能更高。** 因为它的利润里没有掺水，而且它把钱花在了未来。
>
> 反过来，**研发资本化比例突然上升**是一个高优先级红旗，尤其当它出现在业绩承压的年份。

还有一个连接下一课的关键点：**资本化会把研发的现金支出从「经营活动」挪到「投资活动」**——于是**利润变好了，经营现金流也变好了，两张表同时被美化**，只有自由现金流不变。这是 Topic 92 会重点拆的把戏。

### 3.4 减值与拨备：「大洗澡」（Big Bath）

坏账准备、存货跌价、商誉减值——这些都是**基于预期的估计**（IFRS 9 的预期信用损失模型甚至要求你预测未来）。估计有区间，于是有两种反向操作：

- **平滑（smoothing）**：好年份多提准备、坏年份少提，把利润曲线拉平——市场喜欢稳定，**但异常平滑的利润本身就是红旗**；
- **大洗澡（big bath）**：新 CEO 上任的第一年，把能减的全减掉、能计提的全计提，把当年做成巨亏（「都是前任的锅」），**为之后几年腾出利润空间**——被冲回的准备会变成未来的利润。

> 📌 **实操信号：** 管理层换届 + 当年巨额减值 + 之后两年利润「强劲反弹」，是一个非常经典的组合。反弹的质量要用现金流去验。

### 3.5 股权激励（SBC）：最常被假装不存在的真实费用

股权激励（Share-Based Compensation）在 **IFRS 2 / ASC 718** 下**必须计入费用**（美国自 2006 年 FAS 123R 起强制）。但在几乎所有科技公司的 non-GAAP 口径里，它是被加回去的第一项。

公司的理由是：「这是非现金费用。」

**这个理由站不住脚。** 巴菲特的反问最有力：

> **「如果股权激励不是薪酬，那它是什么？如果薪酬不是费用，那它是什么？如果费用不该进利润表，那它该进哪儿？」**

经济实质很清楚：公司本可以发现金，选择了发股份；**员工拿到了真实的报酬，老股东付出了真实的代价——被稀释的所有权。** 说它「非现金」是把成本从现金转移到了**股数**上（第六节展开）。

一个更彻底的验证方式：如果 SBC 真的没有成本，为什么这些公司要每年花掉大笔现金**回购股份**来抵消它的稀释？**那笔回购支出，就是 SBC 的现金账单。**

## 四、三条利润率各自在回答什么，以及经营杠杆

### 4.1 三条利润率的分工

| 利润率 | 公式 | 它测量的是 | 高低取决于 |
|---|---|---|---|
| **毛利率** | 毛利 / 收入 | **定价权**：客户愿意为你的东西多付多少 | 品牌、专利、网络效应、转换成本（Topic 95） |
| **营业利润率** | EBIT / 收入 | **经营效率**：把整台机器跑起来后还剩多少 | 费用管控、规模效应、经营杠杆 |
| **净利率** | 净利 / 收入 | 加上**融资与税务**后的最终结果 | 杠杆、税率、一次性损益 |

三者之间的**差额本身就是信息**：

- 毛利率高、营业利润率低 → 钱花在了获客或研发上。**要问的是：这是投资还是失控？** 如果获客成本随规模下降，是投资；如果收入涨了三倍、销售费用也涨三倍，那这门生意可能没有护城河。
- 营业利润率稳定、净利率剧烈波动 → 生意本身没问题，**波动来自杠杆或一次性项目**。
- 毛利率长期下滑 → **最危险的信号之一**：通常意味着定价权在流失（竞争加剧、产品商品化）。它比收入下滑更早出现，也更难逆转。

### 4.2 经营杠杆：为什么收入跌 10%，利润能跌 40%

成本可以分成两类：

- **固定成本**：厂房折旧、研发团队、总部——收入涨跌都得付；
- **可变成本**：原材料、支付手续费——随收入同比例变化。

**固定成本占比越高，利润对收入变化就越敏感。** 这就是**经营杠杆（Operating Leverage）**：

$$\text{DOL} = \frac{\text{营业利润变动率}}{\text{收入变动率}} = \frac{\text{收入} - \text{可变成本}}{\text{营业利润}}$$

它解释了很多让新手困惑的现象：

- **软件公司**收入增长 30%，利润增长 80%——因为多卖一份拷贝的边际成本接近零；
- **航空公司、酒店、半导体厂**在需求下滑 15% 时可以直接从盈利变成巨亏——飞机的折旧、晶圆厂的折旧一分不会少；
- **周期股的 PE 在最景气时看起来最低**（利润被杠杆放到最大），这正是「**周期股要在高 PE 时买、低 PE 时卖**」这句反直觉格言的来源。

而 Topic 87 讲的**财务杠杆（DFL）**在此之上再叠一层：

$$\text{DFL} = \frac{\text{EBIT}}{\text{EBIT} - \text{利息}}, \qquad \boxed{\text{总杠杆 DTL} = \text{DOL} \times \text{DFL}}$$

> 🎯 **两种杠杆是相乘的，不是相加的。** 一家固定成本高（DOL 3）又借了很多钱（DFL 2）的公司，总杠杆是 **6 倍**：收入跌 10%，净利润跌 60%。这就是「**重资产 + 高负债**」这个组合在每一次衰退里都排在死亡名单最前面的数学原因。

## 五、EBITDA 与「调整后利润」：到底调掉了什么

### 5.1 EBITDA：有正当用途，也有原罪

$$\text{EBITDA} = \text{净利润} + \text{利息} + \text{税} + \text{折旧} + \text{摊销}$$

它的**正当用途**有两个：

1. **跨资本结构、跨税收辖区比较**：并购方要比较两家公司的经营能力，不想被「一家借得多、一家借得少」干扰；
2. **债务分析**：净负债 / EBITDA 是银行和评级机构的通用语言（Topic 90 用过）。

它的**原罪**只有一条：**折旧和摊销是真实的成本。** 机器会磨损，服务器会淘汰，门店装修五年后必须重做。EBITDA 假装这些不存在。

两句最著名的批评：

> **芒格：** 「每次你看到『EBITDA』这个词，就应该把它替换成『**狗屁利润**（bullshit earnings）』。」
>
> **巴菲特：** 「难道管理层认为资本开支是由**牙仙**来买单的吗？」

**什么时候 EBITDA 特别具有误导性？**

- **重资产公司**（电信、航空、制造、数据中心）：D&A 巨大，EBITDA 与真实现金流差出十万八千里；
- **需要持续资本开支才能维持现状的公司**：Topic 89 讲的「维持性资本开支」被完全忽略；
- **反过来**，对轻资产的软件公司，EBITDA 与经营现金流的差距较小——但那里的主要扭曲变成了 SBC。

> 📌 **一个实用的替代品：$\text{EBITDA} - \text{资本开支}$**，或者干脆直接用**自由现金流**（Topic 92 会正式定义）。只要一家公司特别热衷于让你看 EBITDA，你就该主动去看它的资本开支。

### 5.2 Non-GAAP：常见调整项与你该怎么看

「调整后净利润」「Non-GAAP EPS」「经调整 EBITDA」——这些数字**不受会计准则约束**，是公司自己定义的。它们不是天然邪恶：剔除一次性并购费用确实能让业绩更可比。**问题在于调整的方向几乎总是单向的。**

| 常见调整项 | 公司的理由 | 你该怎么看 |
|---|---|---|
| **股权激励（SBC）** | 「非现金费用」 | ❌ **不该加回**。它是真实薪酬，代价是股东被稀释（第六节） |
| **并购形成的无形资产摊销** | 「非现金，且与经营无关」 | ⚠️ 部分合理，但**收购本身花了真金白银**；若公司连续并购，它就是经常性的 |
| **重组费用** | 「一次性」 | ⚠️ **看频率**。连续出现三年以上，就是经营成本 |
| **商誉/资产减值** | 「非现金」 | ⚠️ 不流出现金，但它是**过去某次真实现金流出的迟来确认**（Topic 90） |
| **诉讼与和解** | 「非经常」 | ⚠️ 对某些行业（药企、平台）是**结构性的经营成本** |
| **汇兑损益** | 「不可控」 | ✅ 通常合理剔除，但持续单向的汇兑损失说明**没有做该做的对冲**（Topic 86） |
| **疫情/一次性事件相关支出** | 「特殊时期」 | ⚠️ 看具体内容，且要检查是否只调坏的、不调好的 |

### 5.3 一条极其好用的判据

> 🎯 **把公司过去五年的「一次性项目」列成一张表。如果每一年都有，那它就不是一次性的——那是它的经营成本，只不过每年换一个名字。**

学术上这个现象有名字：**non-GAAP 与 GAAP 的差额（adjustment gap）持续扩大的公司，其后续的股价表现与盈利质量系统性偏弱。** 直觉也很简单：**一家生意越好的公司，越不需要发明新的口径来解释自己。**

## 六、EPS：别忘了分母也会动

### 6.1 基本 EPS vs 稀释 EPS

$$\text{基本 EPS} = \frac{\text{归母净利润}}{\text{加权平均普通股股数}}, \qquad \text{稀释 EPS} = \frac{\text{归母净利润}}{\text{假设所有潜在股份都转换后的股数}}$$

「潜在股份」包括：员工期权与限制性股票（RSU）、可转债、认股权证。

> 📌 **永远看稀释 EPS。** 基本 EPS 假装那些已经发出去的期权不存在——但它们**迟早会变成真实的股份，摊薄你手里的每一股**。

### 6.2 EPS 增长可以是「买」来的

EPS 是一个分式，**分子和分母都能动**：

$$\text{EPS 增长} \approx \text{净利润增长} - \text{股数增长}$$

于是就有了一个很常见的现象：**净利润零增长的公司，靠回购 5% 的股份，也能报出 5% 的 EPS 增长。**

这是不是创造价值？**取决于回购价格。**

- 在**低于内在价值**时回购 → 剩下的股东的每股价值确实提升了，是价值创造；
- 在**高于内在价值**时回购 → 相当于用公司的钱高价买入自家股票，**是在毁灭价值**，但 EPS 照样上升。

**问题在于：管理层的奖金往往挂钩 EPS。** 于是「无论价格高低都回购」有了强烈的动机——这在 2018–2021 年的美股是一个被广泛讨论的现象，也是许多公司在 2020 年疫情中现金骤然吃紧的原因之一（Topic 90 提过）。

### 6.3 一个必须算的数：净稀释率

科技公司常见的组合是：**一边大量发行 SBC 稀释股东，一边花现金回购来「抵消」稀释。** 于是股数看起来没怎么变，仿佛 SBC 真的免费。

**正确的算法是把两件事分开看：**

| 项目 | 含义 |
|---|---|
| **总稀释（gross dilution）** | SBC 当年新增的股份 / 期初股数 |
| **回购抵消** | 花在回购上的现金 / 市值 |
| **净稀释（net dilution）** | 两者相减；股数的实际变化 |

> 🎯 **关键判断：那笔用来抵消稀释的回购现金，本质上是薪酬支出，而不是股东回报。** 一家公司宣称「今年回购了 100 亿回馈股东」，如果其中 80 亿只是用来抵消 SBC 的稀释，那真实的股东回报只有 20 亿。**算自由现金流时，SBC 必须被当作成本减掉，否则你会系统性高估一整个行业。**

## 七、盈利质量：把利润表和现金流对起来

这一节是整课的**收口**，也是通往 Topic 92 的桥。

### 7.1 应计项目（Accruals）：利润与现金之间的那道缝

$$\boxed{\text{应计项目} = \text{净利润} - \text{经营现金流}}$$

这个差额本身是**正常存在**的（折旧、营运资本变化、递延收入都会造成差异）。但它的**大小与持续方向**极具信息量：

$$\text{应计比率} = \frac{\text{净利润} - \text{经营现金流}}{\text{平均总资产}}$$

- **应计比率持续为正且偏高** → 利润里有很大一部分是「记出来的」而不是「收进来的」；
- **应计比率为负** → 现金比利润多，通常是保守会计或收到大量预收款的健康特征。

### 7.2 Sloan（1996）：一个被反复验证的实证结论

会计学者 **Richard Sloan 在 1996 年**发表了一项影响深远的研究：**应计项目高的公司，其后续年度的盈利更容易下滑，股票回报也系统性偏低**；应计低（现金占比高）的公司则相反。

背后的原因不神秘：**应计部分的持续性（persistence）低于现金部分**。今年靠放宽信用政策做出来的利润，明年往往要以坏账或收入塌陷的形式还回去。而市场在定价时，倾向于把两种利润**一视同仁**地外推——这就是所谓的「**应计异象（accrual anomaly）**」。

> 📌 **对你的直接含义：** 当两家公司报出同样的每股收益时，**利润里现金含量高的那一家，质量更高。** 这是一个不需要任何高级工具、只需要两张表就能做的筛选。

### 7.3 Beneish M-Score：一个操纵检测的思路

**Messod Beneish（1999）** 构建了一个由 8 个变量组成的模型，用于识别可能存在盈余操纵的公司。常用的判据是：**M-Score > −1.78 时，公司被归类为「可能操纵」的概率显著上升。**

它的 8 个变量分别捕捉：应收账款相对收入的异常增长、毛利率的恶化、资产质量的变化、销售增长、折旧率的下降、销售管理费用的异常、杠杆的变化、以及应计的规模。

**它的价值不在那个分数**（对不同市场与行业的适用性有限，也从不是「证据」），**而在于它挑出的那几个方向**——几乎每一次盈余操纵，都会在这几个地方留下指纹。

### 7.4 一张可以随身带的红旗清单

| 红旗 | 为什么危险 |
|---|---|
| **净利润连年增长，经营现金流原地踏步或下滑** | 利润没有变成钱。**最高优先级的信号，没有之一** |
| **应收账款增速持续快于收入增速** | 可能是压货、放宽信用政策，或客户付不出钱 |
| **存货增速持续快于收入增速** | 卖不动了，减值往往在一两年后到来 |
| **毛利率异常平滑，或与同业趋势相反** | 平滑本身需要「工具」，工具就是准备金 |
| **有效税率突然大幅下降** | 一次性税收利益撑起的利润不可持续 |
| **利润主要来自「其他收益」「投资收益」「公允价值变动」** | 这不是生意在赚钱 |
| **「一次性项目」连续出现三年以上** | 它是经常性成本，换了个名字 |
| **审计师更换、CFO 离职、财报延迟披露** | 会计问题最可靠的先行指标之一 |

## 八、🇸🇬 落地：新加坡投资者的三个场景

### 8.1 单层税制（One-Tier）：净利润在新加坡的含义

新加坡的企业所得税**名义税率为 17%**，并实行**单层税制（one-tier corporate tax system）**：

> **公司缴完所得税后派发的股息，在股东手上是免税的**——个人股东收到新加坡公司的股息不需要再交一次税，也没有股息预扣税（withholding tax）。

对比美国（公司交完税、股东收股息再交一次，且对非美居民通常预扣 30%），这是一个结构性的差异，也是 Topic 57 里讨论「为什么爱尔兰注册的 UCITS ETF 对新加坡投资者更友好」时的同一条逻辑线：**税收摩擦是复利的隐形对手。**

另外两点值得知道：

- 新加坡对企业有**部分免税与起步免税**安排，使得中小公司的**有效税率明显低于 17%**；具体额度以 IRAS 的最新规定为准；
- 在 **BEPS 2.0 / 支柱二**框架下，新加坡自 **2025 年起**对符合门槛的大型跨国企业集团（全球年收入 ≥ 7.5 亿欧元）实施**国内补足税**，把其有效税率补足到 **15%**。这意味着一部分在新加坡的大型跨国公司，**未来的有效税率会上升，净利润会因此下降——而生意本身没变**。读跨年度的净利润时要意识到这一层。

> 📌 这也再次说明第一节那句话：**净利润里混着「你在哪注册」这个与生意无关的变量。EBIT 更适合做跨期与跨国比较。**

### 8.2 银行（DBS / OCBC / UOB）：整张利润表长得不一样

Topic 90 说过银行的资产负债表要换一套读法，利润表同样如此。银行没有「收入 − 成本 = 毛利」这个结构，它的骨架是：

| 层级 | 含义 |
|---|---|
| **净利息收入（NII）** | 利息收入 − 利息支出。银行最主要的收入来源 |
| **净息差（NIM）** | NII / 生息资产。**加息周期的核心变量**：资产端重定价快于负债端时 NIM 扩张 |
| **非利息收入** | 财富管理、信用卡、交易、保险分销的手续费——**波动小、不占用资本，估值上更值钱** |
| **成本收入比（CIR）** | 营业费用 / 总收入。本地大行长期在 40% 上下的水平 |
| **减值拨备（Allowances / ECL）** | IFRS 9 下的预期信用损失。**这是银行利润表里弹性最大的一行** |
| **信贷成本（Credit Cost）** | 拨备 / 贷款总额，通常以基点表示 |

> 🎯 **对银行而言，「拨备」这一行几乎就是利润表的调节阀。** 经济好时多提一般准备（利润被压低）、经济差时回拨（利润被抬高），是银行业普遍存在的平滑行为。所以看银行利润，**要把「拨备前营业利润（PPOP）」单独拎出来**——它更接近银行真实的赚钱能力，而拨备则告诉你管理层对未来的看法。

### 8.3 S-REIT：净利润这个数字，几乎没有用

这是新加坡投资者最需要注意的一个特例。

S-REIT 的投资性房地产按 IAS 40 以**公允价值**计量（Topic 90 讲过），**每年重估的公允价值变动会直接进入损益表**。后果是：

- 物业估值上调 → 净利润暴增，但**没有一分钱现金进来**；
- 物业估值下调 → 净利润暴跌甚至巨亏，但**分红可能一分不少**。

所以看 S-REIT，**净利润和 EPS 基本没有参考价值**。要看的是这条链：

$$\text{物业收入} \to \text{净物业收入（NPI）} \to \text{可分配收入（Distributable Income）} \to \text{每单位派息（DPU）}$$

**可分配收入**会把公允价值变动等非现金项目剔除掉，是 REIT 版本的「真实盈利」。相应地：

- 估值用 **P/NAV** 和**派息率（yield）**，不用 PE；
- 增长看 **DPU 增长**和**每平方尺租金（rental reversion）**，不看净利润增长；
- 风险看 Topic 90 讲的**杠杆率、利息覆盖倍数与债务到期结构**。

> 📌 **一个立刻可用的检查：** 当你看到某只 S-REIT「净利润同比下降 60%」的新闻标题时，先去公告里找**可分配收入与 DPU**。多数情况下，那 60% 来自物业重估，而 DPU 只变化了几个百分点。**标题引用的是最没用的那一行。**

## 📝 本篇小结

- **利润表是「录像」，回答的是「这段时间赚没赚钱」。但它不是数出来的，是判断出来的**——权责发生制要求管理层判断「收入何时赚到、费用何时发生」，判断有区间，区间就是利润可被合法调节的空间。**利润是观点，现金是事实。**
- **该盯的是营业利润（EBIT），不是净利润。** 净利润底下混着利息（怎么融资）、税（在哪注册）、一次性损益（卖了栋楼）这三样与生意本身无关的东西。这也是 ROIC 用 NOPAT 而非净利润的原因。
- **收入确认是最上面也最难的一行。** IFRS 15 的判据是**控制权转移**；时段确认（完工百分比）是操纵重灾区（东芝）；**总额法与净额法让收入差十几倍而净利不变**；GMV 不是收入。压货的指纹是**应收增速远超收入增速**（瑞幸的教训是：造假者最难伪造的永远是现金）。
- **四个合法假设就能把净利润拉开一倍以上**：折旧年限（微软 FY2023 延长服务器折旧年限，营业利润 +37 亿美元；Alphabet 2023 年净利 +约 30 亿美元）、研发资本化比例、坏账计提率、SBC 是否计入。**互动二里那门生意的现金流全程一动没动。**
- **研发资本化会同时美化利润和经营现金流**（现金支出被挪到投资活动），只有自由现金流不变——这是最难识破的一种，Topic 92 会正式拆开。
- **经营杠杆 × 财务杠杆 = 总杠杆，两者相乘不是相加。** 固定成本高（DOL 3）+ 借得多（DFL 2）= 收入跌 10%、净利跌 60%。这解释了周期股「最景气时 PE 最低」的陷阱。
- **EBITDA 假装折旧不存在**（芒格：「狗屁利润」；巴菲特：「资本开支难道是牙仙买单？」）。**Non-GAAP 调整里，股权激励绝不该被加回**——它是真实薪酬，代价是股东被稀释；**「一次性项目」连续出现三年以上，它就是经营成本。**
- **EPS 的分母也会动**：永远看稀释 EPS；回购能凭空制造 EPS 增长，**是否创造价值取决于回购价格**；用于抵消 SBC 稀释的回购现金，本质是薪酬支出而非股东回报。
- **盈利质量的核心检验只有一个式子：应计 = 净利润 − 经营现金流。** Sloan(1996) 证明应计高的公司未来盈利与回报系统性偏弱。红旗清单里优先级最高的一条：**净利润连年增长，而经营现金流原地踏步。**
- **新加坡三个特例**：单层税制让股息在股东手上免税（但支柱二从 2025 年起把大型跨国集团补足到 15%）；银行要看 NIM、CIR 与**拨备前营业利润**；**S-REIT 的净利润几乎无用**，要看可分配收入与 DPU。

**下一课预告 —— Topic 92：读财报（三）：现金流量表 —— 账面利润 ≠ 真有钱。** 这一课我们反复说「拿现金流去验利润」，下一课就去把那张表本身拆开：经营、投资、筹资三栏各自意味着什么，「净利润 → 经营现金流」的调节过程如何暴露前两课里所有的把戏，以及那个最终决定公司价值的数字——**自由现金流**——到底该怎么算，为什么每个人算出来的都不一样。
